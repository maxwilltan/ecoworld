EcoWorld Pile Efficiency & Design Review — Supabase-connected site

Upload the contents of this folder to GitHub with index.html at the repository root.
This site connects to the existing EcoWorld Supabase project. The required
connection is in js/supabase-portal.js; keep it in the index.html script order.

The database schema and security migration are already applied to the connected
project. SQL files and the database diagram are not needed to run this site, so
they are omitted from this deployment package.

Sign in with an existing Supabase Auth account. Older browser-only submissions
and drawings are not migrated automatically. No secret/service-role key is in
this package.
