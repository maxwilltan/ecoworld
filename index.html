How to use Paste from Excel

Example format

  1. Prepare your Excel table with exactly 5 columns.
  2. The order must be: Column Numbering, Pile Type, Pile Size, No of Piles, and Column Loading.
  3. Select the rows in Excel, copy them, then paste directly into the text box.
  4. Header rows are accepted, so you can copy together with the yellow title row.
